# `devopt` memory 伪共享输出格式

## 当前记录格式

`/XXXXX/devopt.sh script -t memory -i <rawdata>` 输出一条头部和两个缩进端点；`/XXXXX` 表示用户解压工具包后的实际目录：

```text
FS 1: 0x400e6c <-> 0x400e6c Type:SS CacheLineAddr:0x17ac40c0 Access Info: A:+0x23,1B;B:+0x1a,1B
   A: worker@/home/user/workspace/false-sharing-master/false:59
   B: worker@/home/user/workspace/false-sharing-master/false:59
```

某些界面会把行首空格显示为 `&#x20;`。解析前将 HTML 实体还原为空格；缩进只是展示格式，不属于字段值。

一条记录由以下字段组成：

- 首词 `FS`：伪共享候选记录类别；其他类别不在本 skill 的分析范围内。
- `1`：该类别内的排名。
- `0x400e6c <-> 0x400e6c`：A、B 两个代表性内存访问指令地址。
- `Type:SS`：访问关系；`SS` 表示写/写，`SL` 表示写/读。这里的 `Type` 不等于行首的 `FS` 类别。
- `CacheLineAddr:0x17ac40c0`：本次运行中对象实例所在的虚拟缓存行基地址。
- `Access Info`：A、B 的行内偏移和访问宽度，当前格式为 `A:+0x23,1B;B:+0x1a,1B`；A 访问 `[0x23, 0x24)`，B 访问 `[0x1a, 0x1b)`。
- `A:`/`B:` 行：符号化端点，格式为 `FUNCTION@MODULE_OR_BINARY:LINE`。从末尾数字行号向左解析，避免路径内容干扰。

`CacheLineAddr` 只对本次进程运行有效，不能跨进程比较，也不能单独证明对应哪个源码变量。

PC 也不是跨构建环境稳定的标识。agent 与被采样应用可能使用不同机器、容器、编译器、链接器、选项或加载基址；只有文件哈希或 build-id 等证据确认是同一构建产物，并正确处理 PIE/ASLR 后，才能直接比较 PC。采样记录中的 PC 与 agent 环境反汇编得到的 PC 不同，本身不能证明记录来自旧构建。

## 示例判定

示例中的访问区间是：

```text
A: +0x23,1B -> [35,36)
B: +0x1a,1B -> [26,27)
```

两个区间不重叠，因此它是伪共享候选。A、B 的 PC、函数和源码行完全相同并不构成反证：同一条带索引或指针的指令可以访问同一缓存行内的不同字节。必须继续检查第 59 行的完整表达式、线程参数、对象基址和字段/元素所有权。

## 记录边界与解析规则

1. 以匹配 `^FS <rank>:` 的行为新记录开始，忽略其他类别。
2. 将紧随其后的 `A:` 和 `B:` 行归入该记录；空行和展示缩进可以忽略。
3. 头部缺字段、A/B 端点缺失、十六进制偏移非法或宽度无法解析时，保留原始记录并标记“未解析”，不要猜测。
4. 按 `CacheLineAddr` 聚合同一次报告中的 `FS` 记录，再按排名分析；不要跨进程或跨次采集用虚拟地址直接关联对象。
5. 同一缓存行有多条记录时先收集全部端点，避免修复一对访问后把争用转移到第三个字段。

## 字节区间判定

把偏移和宽度换算为半开区间，避免把“相邻”误判为“重叠”：

| 端点 A | 端点 B | 交集 | 初步解释 |
| --- | --- | --- | --- |
| `+0x0,8B` → `[0,8)` | `+0x8,8B` → `[8,16)` | 无 | 不同线程独立写入时是伪共享候选 |
| `+0x4,8B` → `[4,12)` | `+0x8,8B` → `[8,16)` | `[8,12)` | 存在同一字节访问，不属于伪共享，排除 |
| `+0x3c,8B` → `[60,68)` | 当前行内另一访问 | 取当前行部分 | A 跨行，需分别检查两个缓存行 |

区间不重叠只是伪共享的必要线索，还必须确认两个端点属于并发执行单元、访问不同逻辑值，并映射到同一对象实例。

## 解释限制

- 采样可能遗漏访问，也可能只选择一组访问中的代表性端点。
- 无法读取或解码指令时，访问宽度可能使用工具的回退值；不要把回退宽度当成已验证布局。
- ASLR、PIE、JIT、不同编译/链接环境、缺失或过期的调试信息、内联及优化都可能导致 PC 不同或源码映射不准确；不要仅凭 PC 差异判断构建新旧。
- 同一源码行可能访问多个字段；表达式不唯一时，应结合 PC、反汇编和 A/B 偏移确认。
- 对象内部字段已经隔离时，相邻堆对象仍可能落在同一缓存行。
- `FS` 分类不能取代源码语义：若两个端点最终访问同一逻辑值，应从伪共享分析中排除。
